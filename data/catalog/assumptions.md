# Sprint 2 assumptions

This is the builder’s assumption log. It is not a review and it is not a sign-off.

1. The snapshot covers model years 2006 through 2027. 2027 is the newest year that both FuelEconomy.gov `vehicles.csv` and NHTSA vPIC returned on 21 September 2026.
2. FuelEconomy.gov `baseModel` is joined to the NHTSA model. The FuelEconomy.gov `model` string is the trim. No marketing trim (XLT, Lariat, or otherwise) was typed in.
3. Confidence is high when those base names agree, allowing only generic body or drivetrain suffixes such as 4WD or 4Dr. A slash in the FuelEconomy name, or a prefix that adds an identity word such as Lightning, is limited. An NHTSA passenger car or multipurpose passenger vehicle with no FuelEconomy join is one row named “Trim not resolved”.
4. NHTSA truck models with no FuelEconomy join are omitted. That drops Super Duty and medium-duty names such as F-250 and F-650. They are outside the FuelEconomy light-duty file, so no trim was invented for them. Ram 2500, Ram 3500, Ram 4000, Ram 4500, Ram 5500, and Ford E-450 are omitted even when NHTSA tags them as a multipurpose passenger vehicle. Those are commercial chassis cabs, not personal light-duty rows. The source diff lists examples. Chassis, motorhome, trailer, bus, motorcycle, taxi, robotaxi, hearse, and limo names are excluded from both feeds.
5. A FuelEconomy make that NHTSA did not return for passenger car, truck, or multipurpose passenger vehicle stays in the snapshot under the FuelEconomy spelling at limited confidence. Scion is one of those makes.
6. Sample dollar weights for Ford F-150, Toyota RAV4, and Tesla Model Y are the sprint 1 sample display weights. Every other catalog vehicle uses weight 1. Those weights are not rating factors. Weak trim confidence changes the label only. The factor engine is a later sprint.
7. VIN decode is a browser call to `https://vpic.nhtsa.dot.gov/api/vehicles/DecodeVinValues/{vin}?format=json`. NHTSA must return error code 0. The field is cleared after the request. A failed decode does not change the picker. A trim hint fills a row only when it is the snapshot trim’s full name. A short hint such as 4WD, or a partial hint such as Raptor, does not select a confident trim the decode did not name. If the hint does not name a snapshot trim, the current row stays when it is the same model; otherwise the first high-confidence row is selected and confidence is limited. No trim name is invented.
8. Search filters the snapshot in the browser. The catalog file is static. This server does not keep a vehicle profile.
9. The refresh window is 180 days from 21 September 2026. After 20 March 2027 the confidence line says the snapshot is past its refresh date.
10. `npm run catalog:build` is the refresh job. It writes the snapshot and `data/catalog/source-diff.md`. The raw FuelEconomy file and raw NHTSA responses stay in `.catalog-cache` and are not committed.
11. Each FuelEconomy trim keeps two government fields: the EPA size class (`VClass`, stored as an index `c` into `vehicleClasses`) and the EPA powertrain type (`atvType`, stored as letter codes `p`: e electric, h hybrid, p plug-in hybrid, f fuel cell). A trim with a class and no `p` is gasoline, diesel, flex-fuel, or natural gas. EPA's "Hybrid" includes mild hybrids (for example Range Rover MHEV trims). When one trim name has rows with two powertrains (61 gas-and-hybrid names), both codes are kept. When one name has two classes (three names, 2WD and 4WD rows), the more common class is kept, ties alphabetical.
12. `src/lib/catalog-class.ts` classifies a vehicle from those fields: the trim's own row first, then every other trim of the same model and year if they agree, then the same model in the nearest year. Only when the catalog has nothing does it look at whole words in the name (for example "Hybrid", "PHEV", "Lightning", "Pickup"). It never matches parts of words, so "Range Rover" can't be read as "Ranger".
13. EPA sizes cars by interior room, so some hatchbacks (the 2020 Hyundai Ioniq, the Civic 5-door) are "Large Cars", and EPA first listed the 2022 Ioniq 5 as a large car before moving it to small SUV. We keep EPA's classes as published.
14. `npx tsx scripts/build-vehicle-catalog.ts --enrich` attached these fields on 22 September 2026 without changing any rows or calling NHTSA. A full `npm run catalog:build` on that day hit NHTSA's rate control (HTTP 403) after 167 requests, so the rows are still the 21 September snapshot. The full build now waits 250 ms between uncached NHTSA requests, uses two workers, and stops cleanly on a 403.
